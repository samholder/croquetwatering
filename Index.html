Plain-English Explanation

Existing plan problem: the centre and mid-lawn receive reasonable overlap, but the edge bands and corners only receive the weak outer edge of circular spray.

New plan benefit: edge sprinklers are placed near the boundary and spray inward, so the lawn edge is watered directly with less waste onto paths.

Timing: half-circle edge heads cover about half the area, so they run for 90 minutes. Full-circle inner heads run for 180 minutes.

Weekly movement: Wednesday to Friday use West, Middle, then East North-South lines. Sunday to Tuesday use South, Middle, then North East-West lines. Saturday is the rest and correction day.
